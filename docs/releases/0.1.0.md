# MyGamesAnywhere for Playnite 0.1.0

Connect Playnite to your MGA server, choose a profile, and sign in with its password. The plugin stores a scoped key encrypted for your Windows account.

This release imports games and metadata, fills missing artwork, filters lapsed subscription games by default, and downloads file-backed games with progress, cancellation, resume, and manifest verification. Steam and Xbox records open their stores. Removed installed games remain in your library; uninstall preserves additional files and files whose lengths changed.

Downloads remain files: archive extraction, installer execution, and emulator selection are configured locally. Verification currently checks length and manifest revision; content hashes are not verified by this release.

Requires Playnite SDK 6.16.0 or later and MGA's scoped frontend API. Profile/password sign-in requires MGA 0.2.22 or later. Older compatible servers can use an access key issued in the MGA console.

NO_MIGRATION_NEEDED: release metadata and stricter pagination validation do not change existing settings or install records.
